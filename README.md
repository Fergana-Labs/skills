# Skills

Reusable [Agent Skills](https://code.claude.com/docs/en/skills) from Fergana Labs. Each folder
holds a `SKILL.md` and whatever the skill needs to run.

| Skill | What it does |
| --- | --- |
| [`html-text-editor`](./html-text-editor) | Edit the visible text of static HTML files in the browser, semi-WYSIWYG, and save back to the source without touching markup or CSS. |
| [`dont-pkill-by-pattern`](./dont-pkill-by-pattern) | Stop a local process without accidentally killing unrelated apps or another worktree's server. |
| [`heavi-brake-shoe-lookup`](./heavi-brake-shoe-lookup) | Identify a heavy-truck brake shoe from trusted evidence without guessing from a VIN. |

## Using one

Copy the folder into `~/.claude/skills/` for every project, or `./.claude/skills/` for one.
